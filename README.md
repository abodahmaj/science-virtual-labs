# 🧪 بوابة العلوم التفاعلية

منصة تعليمية تفاعلية لمناهج العلوم في المرحلة المتوسطة، تضم مختبرات افتراضية، مراجعات تفاعلية، اختبارات إلكترونية، وبوابة تدريب محاكية للاختبارات الوطنية (**نافس**).

**إعداد:** أ. علي جبريل — مجمع الثقافة التعليمي  
🌐 **رابط البوابة:** [abodahmaj.github.io/science-virtual-labs](https://abodahmaj.github.io/science-virtual-labs/)

---

## ✨ محتويات البوابة
- **المختبرات الافتراضية:** محاكاة تفاعلية للمفاهيم والتجارب العلمية بتصميم مناسب للبروجكتر والأجهزة اللوحية.
- **بوابة نافس والاختبارات:** اختبارات إلكترونية ومحاكية لتدريب الطلاب وقياس نواتج التعلم.
- **المراجعات والتقارير:** ملخصات ومراجعات تفاعلية وتقارير لمتابعة الأداء.
