## ⚙️ مميزات المختبرات
1. **دقة فيزيائية ورياضية:** تطبيق معادلات التشتت والتصادم ونسب الجسيمات الواقعية.
2. **محسّنة للمس والآيباد:** مساحات لمس تتجاوز 54 بكسل مع منع السحب غير المقصود.
3. **وضوح عالي للبروجكتر:** مساحة عرض رحبة وألوان ذات تباين نيون فائق الوضوح.
4. **تعمل دون إنترنت:** جميع المعامل مبنية بملفات مستقلة ذاتية التشغيل.
